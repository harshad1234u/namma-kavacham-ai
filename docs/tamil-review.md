# Tamil language review — Namma Kavacham AI

**Status: every row is _pending native review_.** No native Tamil speaker has reviewed any suggestion in this
document. The suggestions are a developer's draft. Nothing here has been applied to the app: the Tamil the
app shows today is the "Current Tamil" column.

- Prepared: 2026-09-25 (Phase 5)
- Scope: every user-visible Tamil string in the frontend (`frontend/src/i18n/strings.ts`, 253 strings) and the
  backend (rule descriptions, next steps, government comparison text, curated KB text, link checks, AI-template
  and provider notes, 95 strings).
- Suggested changes: 44 frontend, 18 backend. All other rows: no change suggested.

## How to use this document

1. A native Tamil reviewer (ideally someone who writes plain-language public information for Tamil Nadu
   residents) goes through the glossary first. Glossary decisions drive most of the row changes.
2. For each row, the reviewer accepts, edits or rejects the suggestion and sets the status to
   `approved`, `approved with edits` or `rejected`, with their name and date.
3. A developer then applies the approved wording. Frontend strings live in `frontend/src/i18n/strings.ts`;
   the backend location is given by the row key (for example `url_analyzer.no_https` →
   `backend/app/services/url_analyzer.py`, `kb.<id>` → `backend/app/data/government_kb.json`).
4. Run the backend and frontend test suites afterwards: some tests assert Tamil text, and the AI output
   validator (`backend/app/services/ai_explainer.py`) matches specific Tamil words.

Rows are generated from the code, so a string added later will not appear here until the table is regenerated.

## Highest-priority findings

1. **"குறிகள்" for "indicators"** (14 strings, both frontend and backend). The word has a vulgar colloquial
   sense in Tamil. "அறிகுறிகள்" (signs, symptoms) is the natural word for warning signs. Note the sandhi
   change: "ஆபத்துக் குறிகள்" → "ஆபத்து அறிகுறிகள்".
2. **"Checked" and "Verified" share one word** ("சரிபார்க்கப்பட்டது"). In a security app, a "Checked" status
   must not read as "Verified". Suggested: "சோதிக்கப்பட்டது" for checked; keep "சரிபார்" for verify and
   "உறுதிசெய்யப்பட்டது" for confirmed.
3. **"Official Civic Advisory" / "அதிகாரப்பூர்வ குடிமை அறிவுரை"** implies the app is a government body.
   This is an English source issue as well; suggest "Civic advisory".
4. **Link-check meaning drift** (`url_analyzer.lookalike_domain_typosquat`). The Tamil says the domain *is*
   a fake-address trick; the English says it is *a typical lookalike pattern*. The Tamil overstates certainty.
5. **Omissions** in five backend link-check strings, which drop part of the English (who gains control of the
   phone, why a pattern matters, the matched path word).
6. **"இணைப்பு" means both "link" and "connection"**, including an electricity connection (மின் இணைப்பு),
   which is exactly the context of electricity-board scams.
7. **"முடக்கப்பட்டுள்ளது" for "turned off"** is the same word scam messages use for "your account will be
   blocked" (முடக்கப்படும்).
8. **Government status labels are inconsistent** after the Phase 5 label change. "Supported" now says
   "official reference" (அதிகாரப்பூர்வ குறிப்பு); the other statuses still say "curated reference"
   (தொகுக்கப்பட்ட குறிப்பு). Align both languages together.

## Style conventions (proposed)

- **Buttons:** short imperative verb stems, as used today (சரிபார், அழி, நீக்கு). **Messages and instructions:**
  the polite -வும் form (சரிபார்க்கவும், அழைக்கவும்).
- **Suffixes after Latin text or a bracket** attach with a hyphen: `cybercrime.gov.in-இல்`, `1930-ஐ`,
  `(…)-க்கு`. Detached forms such as `'evil.in' ஐத்` and `(…) க்கு` are flagged in the tables.
- **Numbers, URLs, domains and helpline numbers** stay in Latin digits and letters, exactly as in English.
- **No certainty the English does not have.** Tamil must not upgrade "may", "typical" or "not found" into
  "is fake", or "matches" into "verified".

## Not covered by this review

- **AI-generated Tamil explanations** (Groq). They are produced at runtime; the code validator checks level,
  numbers, domains and safety claims, but no human reviews individual outputs.
- **Templated backend findings with runtime values** (government comparison findings in
  `backend/app/services/government/kb_comparator.py` that embed a service name or domain). Their fixed
  parts use the same vocabulary as the rows below; the reviewer should read that file directly.
- **Screen-reader output.** Labels are the same strings as the visible text; no separate audio review was done.
- **Official Tamil scheme names.** The Tamil names of PM-JAY and the National Scholarship Portal are
  translations or transliterations, not verified official Tamil names.
